# THE CALL｜棒球主審模擬器

第一人稱 3D 主審遊戲，繁體中文介面。進入後即為滿版球場；判決按鈕與必要資訊覆蓋在球場內，設定、成績與落點分析由齒輪面板開啟。投手、打者與捕手採用真人比例的原創人物插畫，以透明素材放入 3D 球場。保留自然膚色、深藍球衣／護具及白色球褲；投手以準備、抬腿、跨步、出手、收勢及回穩六個關鍵姿勢，配合關節驅動網格變形與連續插值。畫面右側是左打者，待打時看得到胸前與側身，頭看向投手、雙手在後肩持棒，具備重心轉移、抬腳預備及球棒微動；捕手依球路移動手套、接球後收回。主審鏡頭沿本壘與投手丘中線取景，避免左右偏斜。Three.js 隨專案保存，沒有安裝套件的步驟。

v5 站姿比對參考：[MLB 官方 Ump Cam 比賽影片](https://www.mlb.com/brewers/video/brewers-preview-ump-cam-of-misiorowski-s-strikeouts) 約 1 秒的待打畫面。影片只作姿勢與視角參考，遊戲未使用影片畫面或球員肖像。

## 本機執行

在此資料夾執行 `npm start`，開啟 http://127.0.0.1:4186 。Windows 亦可雙擊「開始遊戲.cmd」，伺服器就緒後自動開啟瀏覽器。需 Node.js 18 以上。

## 操作

- 接球後，點擊球場內顯示的「好球」或「壞球」按鈕判決。方向鍵及 A / D 不送出判決。
- 點擊「投下一球」繼續；20 球挑戰最後點「查看結算」。
- 點擊「ABS 判決回放」觀看球路追蹤、穿越本壘板中線與判決定格；可切換轉播、正面、側面視角，按「重播」重新播放，按「返回主審」離開。
- Space：下一球／結算；R：開關回放；P：暫停。所有操作均有畫面按鈕。
- 正式挑戰共 20 球；自由練習不限球數，可開關好球帶。離開頁籤或開啟說明會暫停。

## ABS 判定與回放

參考 MLB 官方 ABS 說明：https://www.mlb.com/interactive/mlb-abs-system-explainer 。本作回放視覺為獨立實作，未使用 MLB 商標、轉播影像或商用球員模型。

為使判決、計分、落點圖和回放一致，本作統一採 ABS 本壘板中線矩形：寬 43.18 公分，固定打者身高 188 公分，上下限分別為身高的 53.5% 與 27%。用球心在中線平面的交點及球半徑計算矩形相交，角落使用圓形距離而非球的外接方框。

回放顯示原始判決、ABS 結果、維持／改判和球體接觸或偏離好球帶的距離；最後定格由玩家自行關閉。這是訓練用每球回放，不模擬球隊挑戰次數。

每次正確判決 100 分，連續答對每球增加 10 分（加成上限 100 分），邊角球另加 50 分。球數依玩家判決推進。三振、保送後更新打席，三出局後重置出局數。

## GitHub Pages

本專案使用 GitHub Pages，未使用 Sites 部署。`.github/workflows/pages.yml` 會先執行規則測試，再將 `dist/` 發布到 GitHub Pages。

1. 將專案上傳至 GitHub 原始碼庫的 `main` 分支。
2. 到 Settings → Pages → Build and deployment，將 Source 設為 GitHub Actions。
3. 執行「Test and deploy THE CALL to GitHub Pages」工作流程，成功後開啟其輸出的 Pages URL。

所有資源均使用相對路徑，支援 `https://<帳號>.github.io/<專案>/` 子路徑。Google 字型無網路時會使用系統字型；其餘遊戲資源已放在專案內。

## 檔案與驗證

- `dist/engine.js`：ABS 中線判定、球路、球數與評分。
- `dist/illustrated-players.js`：人物動作、接球目標與場景位置。
- `dist/motion.js`、`dist/painted-rig.js`：人體關節標記、連續姿勢插值與細分網格變形。
- `dist/stage.css`：滿版球場與場內操作介面。
- `dist/assets/`：原創打者、捕手、投手動作圖；提示紀錄見 `assets-prompts.md`。
- `dist/players.js`：程序生成的人體模型，作為場景動畫與人物比例參考。
- `dist/scene.js`：主審視角、夜間球場、材質、陰影與人物動作。
- `dist/abs-replay.js`：獨立 ABS 回放場景與鏡頭。
- `dist/app.js`：狀態機、畫面按鈕、音效、每個難度的最佳紀錄。
- `tests/engine.test.mjs`：ABS 中線、球體擦邊、角落、計分與比賽流程測試。

執行 `npm test` 驗證核心規則、動作插值連續性、繪圖網格不變性與捕手接球投影。人物是原創插畫素材，投球動畫以六個關鍵插畫姿勢進行連續網格變形，並非掃描真人或動作捕捉；不含揮棒、跑壘、比分及九局完整比賽。入門難度放慢可見球路，km/h 為球種標示速度。
